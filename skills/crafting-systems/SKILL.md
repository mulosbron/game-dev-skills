# Crafting Systems

> Razbuten's thesis: optional crafting gets ignored. The default advice is not "add crafting" but "either bury it in the core loop or remove it".

## The one critical question
**Can the player finish the game without ever opening the crafting menu?** If yes, the system is decoration. Either tie progression to crafting or cut the system; there is no middle ground.

## Three pillars

**1. Embedded in the core loop.** Resources tied to specific biomes → gathering feeds exploration → crafted gear unlocks going deeper. Subnautica: explore → gather → craft → survive → go deeper. Fallout 4: shops sell the same items, crafting is "another currency", nobody uses it.

**2. No constraint, no choice.** Unlimited inventory turns every resource into a statistic; the player hoards everything and uses nothing. The Last of Us Part II: the same scraps make a medkit, a molotov or ammo? Space is tight, materials are scarce, every decision is felt. Consumables break hoarding.

**3. Tactile weight.** Click → item appears: forgettable. Skinning in RDR2, the forging ritual in Dragon Quest XI: the process matches the value of the result. Fewer, meaningful, animated creations instead of a hundred identical clicks.

## Diagnosis
- Does a shop sell the same thing crafting produces? → Remove one of them.
- Is the player hoarding "just in case"? → Shrink capacity, make items consumable.
- Does crafting feel like filling in a form? → Add time, animation and sound to the moment of creation.

## Don't
Don't add crafting to tick a feature box. Don't leave it optional. Don't give unlimited inventory. Don't ship hundreds of identical recipes.
