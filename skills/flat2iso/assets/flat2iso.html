1. Column shifting (Lotovik "2-pixel selection" trick)

The flat drawing is split into vertical columns of steps pixels wide; each subsequent column shifts up by 1 pixel relative to the previous one. With steps = 2 you get an exact 2:1 (≈26.57°) slope. Vertical lines remain undistorted, and horizontal lines turn into clean 2:1 staircases. The tool never blends pixels: each source pixel maps to exactly one target pixel, with zero anti-aliasing.

2. Incursio Flat2Iso logic

  • Steps: number of columns kept at the same height (1 = 45°, 2 = 2:1, 3 = 3:1…).
  • Direction: Right (rises right), Left (rises left), Split (rises both ways from center). In Split mode, you choose the center column.
  • Parity rule: even steps for even-width objects and odd steps for odd-width objects are preferred; the tool warns on mismatch.

3. Box builder (lightweight PixZels approach)

Takes Front + Right Side + Top views. Front goes on the left face (rising 1 px every 2 columns away from the corner), and Side goes on the right face with the same rule. The Top face is projected onto a 2:1 diamond via inverse mapping (dest → source) for each target pixel, preventing holes or overlaps and aligning diamond edges pixel-for-pixel with the top staircases of the side faces. Lighting follows the classic 3-face system; the outline color (darkest color on the face) can optionally be protected from lighting.

4 directions: If Back and Left Side are omitted, they are generated by mirroring Front and Right; the Top view is rotated in 90° increments.

Rules

  • All horizontally sloped lines are 2:1 (guaranteed with steps = 2).
  • Vertical lines stay completely straight.
  • Zero anti-aliasing / blur anywhere; all sampling is nearest-neighbor.
  • For upscaled sources (e.g. 8×), use "Pixel scale → Auto" to reduce to true pixel size, then upscale again with "Export scale".
