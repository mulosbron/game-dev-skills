# Technical Process & Tools

## Engine Choice

The engine matters less than the discipline of sticking with one.

- **2D:** GameMaker, Godot
- **3D:** Unity, Unreal
- **Don't engine-hop.** Mastery beats the "right" choice.

## Coding Discipline

Avoid tutorial hell — the state of watching tutorials endlessly without being able to build independently. Question every copied line: "Why is this here?" Understanding code is the foundation of game development.

## Lower Production Costs

Don't reinvent the wheel. Use:
- Asset stores for art, audio, UI
- Stock music libraries
- AI tools for repetitive tasks (texture generation, placeholder art, localization drafts)

Compete on creativity, not graphical fidelity. AAA studios win on assets; indie wins on ideas.

## Build Pipeline

Learn the export/build process early. Features that work in the editor can break in a shipped build. Test on target platforms regularly, not just at the end.

## AI as a Lever

AI tools are not a threat — they're a force multiplier for small teams. Use them for:
- Placeholder assets during prototyping
- Texture and sprite generation
- Audio and music drafts
- Localization and copy
- Code scaffolding and boilerplate

The leverage is in speed; the craft is in curation.
